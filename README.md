
# AI智能伙伴

基于大语言模型 API 开发的智能聊天应用，支持 AI 角色定制、多会话管理及历史数据持久化，实现类似 ChatGPT 的多轮对话体验。

## 技术栈

- Python 3.10+
- Streamlit
- DeepSeek API（OpenAI Compatible）
- JSON 文件存储

## 安装与配置

### 环境要求

- Python 3.10+
- DeepSeek API Key

### 安装依赖

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
